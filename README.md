# jar-runner

Программа для запуска jar файлов с разными параметрами JVM

## Описание

**jar-runner** — это графическое приложение на Java Swing, которое позволяет удобно запускать JAR-файлы Java-приложений с контролем параметров JVM и мониторингом вывода.

## Возможности

- 🚀 Запуск и остановка JAR-приложений через графический интерфейс
- ⚙️ Настройка флагов и параметров JVM
- 📋 Просмотр вывода приложения в реальном времени (журнал)
- 🔍 Отображение PID запущенного процесса
- 📊 Табличное представление параметров JVM

## Требования

- Java 11 или выше
- Maven 3.x

## Сборка и запуск

### Сборка проекта

```bash
mvn clean package
```

### Запуск приложения

```bash
java -jar target/jar-runner-1.0.jar
```

Или через Maven:

```bash
mvn exec:java -Dexec.mainClass="ru.isokolov.jar.runner.App"
```

### Отладка

Для запуска в режиме отладки используйте стандартные параметры JVM:

```bash
java -agentlib:jdwp=transport=dt_socket,server=y,suspend=y,address=8000 -jar target/jar-runner-1.0.jar
```

Затем подключите отладчик к порту `8000`.

## Структура проекта

```
src/main/java/ru/isokolov/jar/runner/
├── App.java                      # Точка входа Swing приложения
├── PrimaryController.java        # Контроллер главного экрана
├── JarApplicationProcessor.java  # Управление процессом запуска JAR
└── JInfoData.java                # Модель данных для отображения информации JVM
```

## Использование

1. Укажите путь к JAR-файлу в поле "Программа"
2. При необходимости настройте параметры JVM во вкладке "Параметры"
3. Нажмите кнопку "Пуск" для запуска приложения
4. Следите за выводом приложения во вкладке "Журнал"
5. Для остановки нажмите кнопку "Стоп"
